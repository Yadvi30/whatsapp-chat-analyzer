# 📊 WhatsApp Chat Analyzer

An interactive web application built using **Streamlit** that analyzes WhatsApp chat data and provides meaningful insights through visualizations and statistics.

---

## 🚀 Features

* 📈 Total Messages, Words, Media & Links statistics
* 📅 Monthly and Daily Timeline analysis
* 🔥 Activity Map (Most active days & months)
* 👥 Most active users in group chats
* ☁️ WordCloud visualization
* 💬 Most common words analysis
* 😀 Emoji usage analysis

---

## 🛠️ Tech Stack

* Python
* Pandas
* Streamlit
* Matplotlib
* Seaborn
* WordCloud

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/yadvi30/whatsapp-chat-analyzer.git
cd whatsapp-chat-analyzer
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
streamlit run app.py
```
